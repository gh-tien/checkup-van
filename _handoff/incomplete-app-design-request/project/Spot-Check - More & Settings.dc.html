2New direction — More as the depot's state, Settings as sentences

All three are live: tap the numbers, the peek rows, the arm-to-empty. Nothing new is invented visually — dashed = provisional or needs you, navy = the one accent, red = a defect or a loss, mono = machine values. What changes is what the screen is for: More stops being a list of destinations and starts saying what is on you.

2aMore — "on you" first, then peek-in-place

The two things blocking work are lifted out of the list and given the verb: Publish v5, Draw one of these next. Coverage's one alarming number becomes the grid it describes, in the row itself. The quiet rows below expand in place instead of navigating — three names is enough to answer "who's on?" without losing your place on More.

2bMore — tiles, one screen, no scroll

Same information, read as a board: number first, name second. Dashed tiles are the ones waiting on you, so "what needs me" is a glance rather than a read. Cheaper to build than 2a and it fits without scrolling — but it loses the verb, so every tile still costs a tap to act on.

2cSettings — the draw rules as one sentence

Four labelled boxes became one sentence with the numbers tappable inside it, so the rule reads as the rule instead of as a form. Tapping a number opens a thumb-sized stepper that clamps to the allowed range — the invalid state the current screen has to explain in red can no longer be typed. Backup becomes a state ("12 days ago, 31 checks since") rather than a pair of buttons, and Empty is folded away until asked for.
